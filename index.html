The Cerebro Factory Super-Intelligence project monitors manufactured goods on the factory lines and performs automated QA and captures product loss using machine vision models. With cameras installed throughout all the different plants, it becomes a challenge to feed the frames from the ip cameras to the models. The next challenge is to prepare media files that allow live streaming. The Cerebro Live Streaming (CLS) project is the solution for prepping hls media files for streaming camera feed to a webapp. Increasing visibility on the problematic camera is important. In this project, I created a visualization component to show the status of hundreds of cameras

The Visual Quality System (VQS) Wonderbrands is an app that is used to display the acceptable versions of all the products made by wonderbrands. This app is placed on the QA lines where workers have a constant reference for the acceptable standard for the product. I used .NET 4.7 Framework MVC, EDMX files to connect to DB, bootstrap, Graph APIs, ajax calls, async image downloading.

The Cerebro Shift Report is a standalone webapp used by factory line managers to make data entries. They use it to keep track of batter losses per work shift and additional information regarding the shift.
